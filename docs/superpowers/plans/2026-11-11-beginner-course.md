# 초보자 교육과정 재구성 작업 계획

> 문서 중심 작업이며 이 세션에서 직접 작성한다. 실행 가능한 예제와 링크를 검증하고 검증 범위를 아래에 남긴다.

**Goal:** 기존 자료를 초보자가 순서대로 읽고 작은 주문 집계를 완성하는 과정으로 재구성한다.

**Architecture:** `docs/course/`에 짧은 입문 본문, `docs/labs/`와 `labs/`에 안내와 실행 파일, `data/`에 공통 데이터를 둔다. 기존 6개 문서는 경로를 보존한 심화 자료로 연결한다.

**Tech Stack:** 한국어 Markdown, Mermaid, Python 표준 라이브러리, PySpark, Databricks SQL.

**Spec:** [재구성 원칙](../specs/2026-11-11-beginner-course-design.md).

## 공통 제약

기존 링크·PNG를 보존한다. 입문 실습의 데이터·지표를 통일한다. 제공한 내용과 미제공 후속 과정을 구분한다. 계정 없는 학습 경로를 제공한다.

## 검토할 실패 조건

- SQL·플랫폼을 모르는 독자가 선수 지식 설명 없이 실습에 진입하는 경우
- 계정·컴퓨트·카탈로그 생성 권한이 없는 경우
- 노트북 셀 순서를 건너뛰거나 세션이 초기화된 경우
- 중복·취소·음수 입력 및 같은 파이프라인 재실행
- 기존 경로, 상대 링크, 이미지 또는 앵커가 끊긴 경우

## 작업

- [x] 1. README, 00–04장: 문제에서 저장 구조까지 연결하고 학습 환경을 구분한다.
- [x] 2. 05–09장과 실습 1–3: 공통 CSV와 실행 파일, 기대 결과, 오류 해결을 제공한다.
- [x] 3. 10–11장, 용어집, 로드맵, 심화 색인: 기존 자료 전체와 후속 학습을 연결한다.
- [x] 4. 기존 문서에 심화 안내·복귀 경로를 추가하고 링크·예제를 검증한다.

| 변경 형식 | `git diff --cached --check` | 통과 |

SQL의 로컬 계산 검사는 관계 연산과 품질 조건을 확인한 것이다. **Spark 분산 실행, Databricks 노트북 실행, Unity Catalog 권한, Delta 저장·교체 동작은 실제 Databricks 환경에서 검증하지 않았다.** 연결된 교육 환경이 준비되면 실습 2·3을 실행하고 사용한 Runtime·컴퓨트·권한과 결과를 추가로 기록한다. 새 런타임 의존성이나 검사용 패키지를 교육 저장소에 추가하지 않았다.
