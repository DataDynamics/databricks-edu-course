# 초보자 교육과정 재구성 원칙

## 목적과 범위

사용자 요청: 아직 미완성인 전체 교육과정을 초보자가 논리적으로 이해하도록 새 브랜치에서 재구성한다. 파일 추가와 세분화를 허용했다.

작성 기준: Python 기초를 조금 접한 개발자, 데이터 엔지니어링·Databricks·SQL은 입문 수준. 대상 수준에 추가 답변이 없으면 이 기준을 사용한다. 문법 자체의 완결 강좌는 제공하지 않고 준비 경로를 연결한다.

## 구성 방식 검토

| 방식 | 장점 | 한계 |
| --- | --- | --- |
| 기존 문서의 목차 순서만 변경 | 변경량이 작음 | JDBC·분산 알고리즘 등 긴 문서 내부의 난도 상승이 남음 |
| 원문을 모두 이동·분할 | 내용 중복을 줄임 | 기존 링크·그림 문맥을 바꾸고 입문/심화 경계가 흐려질 수 있음 |
| 입문 본문을 별도로 구성하고 원문을 심화로 연결 | 짧고 연속적인 학습 경로, 기존 링크 보존 | 개념 요약과 원문의 일관성을 관리해야 함 |

세 번째 방식을 작성자가 선택한다. 새 과정은 단순 링크 모음이 아니라 장마다 개념·예제·확인 문제를 제공한다. 기존 문서는 상세 참고 자료로 명시하고 해당 입문 장으로 돌아가는 링크를 넣는다.

## 학습 순서

00 시작 → 01 업무 질문 → 02 데이터·SQL 기초 → 03 저장과 계산 → 04 Lakehouse → 05 Python → 06 Spark → 07 Databricks → 08 Unity Catalog → 09 파이프라인 → 10 분석·AI → 11 운영·복습.

실습은 로컬 Python, 세션 안의 PySpark·SQL, 관리형 Delta 테이블 순서로 환경 요구를 높인다. 하나의 5행 데이터셋을 사용하며 결제 완료 금액은 book=20000, food=15000이다. 데이터에 날짜·환불이 없으므로 결과를 일별 매출 또는 순매출이라고 부르지 않는다.

## 제약과 완료 기준

- 한국어 Markdown과 기존 PNG를 활용한다. 별도 웹사이트·빌드 시스템은 추가하지 않는다.
- 기존 6개 문서의 경로·명시적 앵커·그림을 보존한다.
- 모든 입문 장에 학습 목표·선수 지식·확인 문제와 해설·이전/다음 링크를 제공한다.
- 설치나 관리자 권한이 필요한 심화 기능을 입문 필수로 만들지 않는다.
- 실습 3은 개인 연습 스키마의 지정된 테이블만 교체하며 재실행 의미를 설명한다.
- 새 제품/API 설명은 공식 문서를 확인하고 관련 위치에 출처를 둔다.
- 로컬에서 실행 가능한 실습은 실제 실행한다. Databricks 실행 여부를 구분해 기록한다.
- 미제공 내용은 후속 과정으로 표시한다. 기존 개념 설명을 완결 실습으로 표시하지 않는다.

## 검증

문서·이미지·앵커 링크와 학습 동선을 검사한다. CSV, Python, PySpark, SQL 예제의 입력·집계 결과 일치를 확인한다. Python 문법과 Databricks SQL 구문을 검사하며, 원격 권한·컴퓨트·Delta 저장 동작은 실제 환경 검증이 필요함을 명시한다.
