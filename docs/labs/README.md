# 실습 안내

입문 본문에서 개념을 읽은 다음 아래 순서로 실습합니다. 세 실습은 [같은 주문 5행](../../data/README.md)으로 같은 금액을 구합니다.

| 실습 | 읽고 올 장 | 실행 환경 | 생성·변경하는 것 |
| --- | --- | --- | --- |
| [1. 로컬 Python](01-local-python.md) | 01–05 | Python 3, 추가 패키지 없음 | 없음. CSV를 읽고 화면에 출력 |
| [2. PySpark와 SQL](02-pyspark-sql.md) | 06–07 | Databricks Python/Spark 노트북 컴퓨트 | 현재 세션의 DataFrame·`orders` 임시 뷰 |
| [3. 관리형 테이블 파이프라인](03-medallion.md) | 08–09 | Unity Catalog 연습 공간, SQL 실행 컴퓨트 | 개인 스키마의 `edu_` 접두사 테이블 3개를 생성·교체 |

실습 1만 로컬 터미널에서 바로 실행합니다. 실습 2의 `.py`와 실습 3의 `.sql`은 **Databricks 소스 노트북**입니다. [Workspace의 Import로 파일을 가져오면](https://docs.databricks.com/aws/en/notebooks/notebook-export-import) 셀 구분이 유지됩니다. 파일 선택 메뉴의 이름·위치는 환경에 따라 다를 수 있습니다.

## 실행 전 확인

- **실습 1:** `python3 --version`으로 Python 3를 확인하고 저장소 파일을 준비합니다.
- **실습 2:** 노트북을 만들거나 가져올 수 있고, Python·Spark 지원 컴퓨트에 연결할 수 있어야 합니다. 영구 테이블 생성 권한은 사용하지 않습니다.
- **실습 3:** 사용할 카탈로그·개인 스키마 이름과 권한을 확인합니다. 이름·권한 준비는 실습 3 안내에 있습니다.

실습 2·3에서는 컴퓨트·저장소 사용에 비용이 발생할 수 있습니다. 기관이 제공한 교육 환경을 사용하고, 실습 후 본인이 시작한 컴퓨트의 종료·자동 종료 설정을 확인합니다. 비용이나 무료 이용 가능 여부를 이 자료에서 보장하지 않습니다.

## 실행할 수 없을 때

| 상황 | 다음 행동 |
| --- | --- |
| 계정이 없음 | 실습 1을 실행하고 2·3의 코드와 기대 결과를 읽음 |
| 컴퓨트 사용 권한이 없음 | 교육 담당자에게 노트북용 실행 환경을 요청 |
| 카탈로그·테이블 권한이 없음 | 실습 2까지 완료하고 개인 연습 스키마 준비 후 3으로 진행 |
| 셀 순서를 잃음 | 입력부터 위에서 아래로 재실행 |
| 검증 실패 | 입력·필터·자료형·키를 확인; 검증을 지우고 넘어가지 않음 |

## 실습 범위

샘플과 기대 결과는 작고 고정되어 있습니다. 실습 3은 전체 스냅샷 교체 방식이며 증분 적재·운영 작업 자동화가 아닙니다. Databricks에서 실제 실행한 결과는 사용한 컴퓨트·Runtime·권한과 함께 기록합니다. 저장소의 로컬 검증 기록은 [작업·검증 기록](../superpowers/plans/2026-11-11-beginner-course.md)에 있습니다.
