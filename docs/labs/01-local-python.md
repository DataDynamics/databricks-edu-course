# 실습 1. 로컬 Python으로 주문 CSV 집계하기

**연결 본문:** [05. Python으로 첫 집계](../course/05-python.md).

**준비:** Python 3와 저장소 파일. 추가 패키지·데이터베이스·Databricks 계정은 필요하지 않습니다.

**완료 기준:** 5행을 읽어 `paid` 3행을 집계하고 book=20000, food=15000을 확인합니다.

## 1. 파일을 확인합니다

[입력 CSV](../../data/orders.csv)를 열어 `paid` 행 세 개를 손으로 더합니다. [실행 파일](../../labs/01_local_sales.py)은 자신의 파일 위치를 기준으로 CSV를 찾습니다.

## 2. 실행합니다

터미널에서 저장소 최상위 폴더로 이동한 뒤 실행합니다. Windows에서 `python3` 명령이 없다면 설치 환경에 맞게 `python`을 사용합니다.

```bash
python3 --version
python3 labs/01_local_sales.py
```

```text
입력 5행 / 결제 완료 3행
book: 20000
food: 15000
전체 결제 완료 금액: 35000
검증 통과
```

파일을 수정하거나 새 파일을 만들지 않고 화면에 결과를 출력합니다. Python의 `assert`를 샘플 확인에 사용하므로 `-O` 옵션 없이 실행합니다.

## 3. 코드를 읽습니다

| 코드 | 역할 |
| --- | --- |
| `Path(__file__)` | 실행 파일의 위치에서 데이터 경로 찾기 |
| `csv.DictReader` | CSV 헤더를 열 이름으로 사용 |
| `int(...)` | 문자 형태의 숫자를 정수로 해석 |
| `if ... == 'paid'` | 업무 규칙에 맞는 행만 선택 |
| `totals.get(..., 0)` | 카테고리별 누적 시작값 선택 |
| `assert` | 고정 샘플의 조건과 정답 확인 |

## 4. 결과를 예측해 봅니다

원본 파일을 바꾸기 전에 다음 결과를 예상합니다.

- 주문 4번을 `paid`로 바꾸면 food=20000, 총 40000입니다.
- 주문 1번이 중복되면 중복 검사가 실패해야 합니다.
- 금액을 `-100`으로 바꾸면 금액 검사가 실패해야 합니다.

직접 변경 실험을 한다면 CSV를 복사해 두고 한 항목씩 바꿉니다. 이 스크립트는 공통 샘플의 행 수·정답을 고정해 검사하므로 정상적인 입력 확장도 정답 검사를 실패시킵니다. 실험 뒤 원래 5행으로 복원하고 다시 실행합니다.

## 막혔을 때

| 증상 | 확인할 것 |
| --- | --- |
| `python3`를 찾을 수 없음 | Python 설치 또는 `python` 명령 사용 여부 |
| 스크립트 파일을 찾을 수 없음 | 현재 터미널 위치가 저장소 최상위인지 |
| `FileNotFoundError` | 저장소 안에 `data/orders.csv`가 함께 있는지 |
| `ValueError` | ID·금액에 숫자가 아닌 문자가 있는지 |
| `AssertionError` | 메시지가 가리키는 규칙 및 공통 샘플과의 차이 |
