# 00. 어떻게 공부할까요?

**학습 목표:** 전체 순서를 이해하고 자신의 실행 환경에 맞는 출발점을 고릅니다.

**선수 지식:** 없음. 이 장에서 필요한 기초를 확인합니다.

## 이번 과정에서 만드는 것

쇼핑몰의 주문 다섯 건을 받아 **결제 완료 상태인 주문의 카테고리별 금액 합계**를 구합니다. 처음에는 손으로, 다음에는 Python으로, 마지막에는 Databricks의 테이블로 같은 질문에 답합니다.

```text
질문과 지표 정의 → 원본 데이터 → 저장과 처리 → 검증된 테이블 → 분석·AI에 제공
```

새 도구가 등장하면 “앞에서 해결하지 못한 어떤 문제를 맡는가?”를 확인합니다. Spark는 처리 규모를, Unity Catalog는 이름과 권한 관리를 이해할 때 배웁니다.

## 기초 준비

| 기초 | 이 과정에서 필요한 수준 | 낯설다면 |
| --- | --- | --- |
| Python | 리스트·딕셔너리, `for`, `if`, 함수 호출, `import`를 읽음 | [Python 공식 튜토리얼](https://docs.python.org/ko/3/tutorial/)의 제어 흐름·자료 구조·입출력부터 확인 |
| SQL | 사전 경험 불필요 | [02장](02-data-basics.md)에서 `SELECT`, `WHERE`, `GROUP BY`를 학습 |
| 파일과 터미널 | 폴더 위치를 확인하고 명령을 실행 | 실습 명령은 저장소 최상위 폴더에서 실행; Windows에서는 환경에 따라 `python3` 대신 `python` 사용 |
| 클라우드·분산 처리 | 사전 경험 불필요 | 03–04장과 06장에서 필요한 개념부터 설명 |

이 자료는 Python·SQL 문법 전체를 가르치는 강좌는 아닙니다. 코드를 읽다가 막히면 기초 문법을 보충한 뒤 같은 예제로 돌아옵니다.

## 내 환경에서 어디까지 할 수 있나요?

| 환경 | 가능한 학습 | 준비 |
| --- | --- | --- |
| 문서만 읽을 수 있음 | 00–11장 개념, 손계산, 확인 문제 | 없음 |
| 로컬 Python 3가 있음 | 위 내용 + 실습 1 | 별도 패키지·클라우드 계정 불필요 |
| Databricks 노트북 실행 가능 | 위 내용 + 실습 2 | Python/Spark 실행용 컴퓨트 사용 권한 |
| Unity Catalog 연습 공간 사용 가능 | 위 내용 + 실습 3 | 연습 카탈로그·스키마 및 테이블 생성/사용 권한 |

환경이 아직 없으면 실습의 코드·기대 결과를 읽고 다음 개념 장으로 진행할 수 있습니다. 다만 실행을 완료한 것과 구분해 학습 기록에 남깁니다. 실제 준비는 [실습 안내](../labs/README.md)를 참고합니다.

## 읽는 순서

1. **01–04장:** 어떤 질문에 답할지, 데이터가 무엇이고 어디에 놓이는지 이해합니다.
2. **05–06장:** 작은 데이터를 처리한 다음 분산 처리가 필요한 이유를 이해합니다.
3. **07–09장:** Databricks에 들어가 실행·관리·저장을 연결합니다.
4. **10–11장:** 결과를 누가 쓰는지, 매일 운영하려면 무엇이 더 필요한지 정리합니다.

각 장의 확인 문제를 먼저 풀고 해설을 펼쳐 봅니다. “더 알아보기”는 선택입니다. JDBC·JVM·K-means·ABAC는 첫 완주 뒤에 공부해도 됩니다.
